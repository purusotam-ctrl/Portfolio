# Purusottam Nanda — Personal Portfolio

A responsive HTML/CSS/JavaScript portfolio with:
- Profile photo
- CV view/download buttons
- About, skills, experience, projects and certifications
- GitHub, LinkedIn and email links
- Responsive navigation and scroll animations
- GitHub Pages-ready structure

## Run locally
Open `index.html` with VS Code Live Server.

## Deploy
Create a GitHub repository, push this folder, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.


## Certificates
The Certifications section is linked from the navbar and uses a scrolling page layout. Each NPTEL certificate has an embedded preview plus an "Open Certificate" button.
